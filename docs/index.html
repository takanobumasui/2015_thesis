建築CAD / CGソフトウェア系譜

1970s–2014年、企業の買収・提携がソフトウェアをどう塗り替えてきたか

このサイトについて

2015年度卒業論文『建築デザインとコンピューター発展の関係 ─『建築雑誌』の記事分析を通して』の資料編「現代における代表的CAD,CGソフトウェア」をもとに構成した、ソフトウェア28本・企業/組織29・プラグイン3の関係ネットワークです。

ノードは企業がソフトウェアを開発した関係（develops）、企業が別の企業やソフトウェアを買収した関係（acquires）などのリンクで結ばれています。下部のタイムラインを動かすと、その年までに存在した勢力図が再生されます。

操作：ドラッグで回転 / ホイールでズーム / ノードをクリックで詳細表示

3D描画には 3d-force-graph（MIT License）を使用しています。
